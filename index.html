Programing Languages

According to the University of York, programming languages: “are ways of writing your commands for the computer. These are then 'run', which means they are translated into something the computer can interpret and then the computer tries to do these commands.” A programming language is essentially the bridge between computer binary and human language. While it may seem complex to the untrained eye it is far more palatable than flat 1s and 0s that make up binary. This research project will cover the history and uses of some of these program languages to give a deeper understanding on them.

Types of languages

There are many different ways to categorize types of programming languages, but the the main way I will be divided them is between front end and back end. Frontend programming contains everything the user sees and interacts with directly, while backend programming contains the unseen inner workings of the application that keeps the application running and manages data.

Frontend languages: HTML, CSS, JavaScript

Backend languages: Python, Java, JavaScript(again)
