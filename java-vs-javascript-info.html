    Java

  • Java is used for general purpose app development. Example include Minecraft, Amazon, and Google Earth.
  • Java source code is compiled into bytecode which is then executed by the JVM.
  • Uses the .java file extension
  • Java variables need to be explicitly declared before use.
  • Java code is class based meaning all code must be contained in a class.

    Javscript

  • JavaScript is used for web development and browser based programs.
  • JavaScripts source code is read and ran directly by web browsers.
  • Uses the .js file extension
  • JavaScripts variable types are assigned at runtime and do not need to be declared.
  • JavaScript is prototype based meaning objects can inheart directly from other objects, making it highly flexible.
