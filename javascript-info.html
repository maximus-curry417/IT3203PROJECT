What is JavaScript?

According to MDN Web Docs “JavaScript is a scripting or programming language that allows you to implement complex features on web pages — every time a web page does more than just sit there and display static information for you to look at — displaying timely content updates, interactive maps, animated 2D/3D graphics, scrolling video jukeboxes, etc. — you can bet that JavaScript is probably involved. It is the third layer of the layer cake of standard web technologies, two of which (HTML and CSS) we have covered in much more detail in other parts of the Learning Area.” Javascript is essentially the engine of an car, no matter how nice it looks without and engine it isn't doing anything but sitting there.

History of JavaScript

JavaScript is a programming language created by Brendan Eich in 1995. The goal of JavaScript was to become a “language of the masses” and help non-programmers be able to create interactive websites. Before JavaScript the web consisted only of static websites, that was until in 1995 a company by the name of Netscape tried to break this barrier by working with Sun Microsystems to embed the Java language into their browser while also hiring Eich to Embed the Scheme language. Netscape later came to the conclusion that having Eich create a brand new language with a similar syntax to Java would be better, and thus JavaScript was born. The name JavaScript might lead you to believe that it is related to Java in some way but this is actually false, Eich believe that Netscape named it Javascript to capitalize of Java’s popularity as a marketing ploy to bring attention to their new language.

Uses of JavaScript

JavaScript is capable of doing standard coding language things such as storing values in variables, basic strings, as well as running commands in response to certain actions. However JavaScript’s nain draw is its Application Programming Interfaces, otherwise known as APIs. APIs are essentially premade templates of code, according to MDN Web Docs “APIs are ready-made sets of code building blocks that allow a developer to implement programs that would otherwise be hard or impossible to implement.” They fall into two categories of Browser APIs and Third Party APIs. Browser APIs are built into your browser and do things like dynamically manipulating HTML and CSS, retrieving geographic locations, creating animated graphics, playing video and audio, and much more. Third party APIs aren't built into the browser and require you to grab their code and information from elsewhere, think things like displaying posts on websites like twitter.
